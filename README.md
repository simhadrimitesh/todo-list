# 📝 My To-Do List

A simple To-Do List website made using HTML, CSS and JavaScript.

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Track total, pending and completed tasks
- Progress bar
- Save tasks using Local Storage
- Font Awesome icons

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage
- Font Awesome
